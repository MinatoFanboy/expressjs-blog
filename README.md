## Setup

### Terminal Commands

1. [Install Node JS](https://nodejs.org/en/download/)
1. Download or clone this repository
1. Install dependencies

    ```bash
    npm install
    ```

1. Start dev server

    ```bash
    npm run start
    ```

1. Open `localhost:3000` on your browser and start coding 🔥

## Usage:

Folder structure:

-   **`src`**: Contains all the logic source code of your ReactJS App. Inside the `src` folder:

    -   **`app/controllers`**: Route controllers to handle requests.
    -   **`app/middlewares`**: Custom middleware functions.
    -   **`app/models`**: Database models/schemas.
    -   **`config`**: Configuration files (database, server, etc.).
    -   **`helpers`**: Utility functions or helper methods that assist for app.
    -   **`public`**: Static files (CSS, JS, images).
    -   **`resources/scss`**: Organize and manage stylesheets written in SCSS (Sass).
    -   **`resources/views`**: Views as well as your raw.
    -   **`routes`**: Route definitions for application.
    -   **`utils`**: Utility functions/helpers.
